ตรวจเครื่องก่อนเล่น

ขั้นตอนสั้น ๆ ใช้เวลาไม่ถึง 2 นาที

ตัวตรวจทำอะไรบ้าง

  • ดูชื่อโปรแกรมที่กำลังรัน และชื่อหน้าต่างที่เปิดอยู่
  • ดู ชื่อ ไฟล์ใน Downloads, Desktop, Documents, AppData (ไม่เปิดอ่านเนื้อหาไฟล์)
  • เทียบกับรายชื่อโปรแกรมต้องห้าม

ส่งไปเซิร์ฟเฉพาะ: ชื่อ Roblox + รหัสสแกน + รายการที่ตรงกับรายชื่อต้องห้าม
ไม่ส่ง: รายการโปรแกรมทั้งหมด, ที่อยู่ไฟล์, รหัสผ่าน, รูปภาพ, เอกสาร

ก่อนส่ง ตัวตรวจจะโชว์ข้อมูลทั้งหมดให้ดู และให้คุณเลือกเองว่าจะส่งหรือไม่ โค้ดเปิดอ่านได้ด้วย Notepad

วิธีใช้

  1. กดปุ่มด้านล่างเพื่อดาวน์โหลด scanner.ps1
  2. เปิดโฟลเดอร์ที่ไฟล์ถูกบันทึก (ปกติคือ Downloads) คลิกที่แถบที่อยู่ด้านบน พิมพ์ powershell แล้วกด Enter
  3. วางคำสั่งนี้ในหน้าต่างสีน้ำเงินแล้วกด Enter: 
    powershell -ExecutionPolicy Bypass -File .\scanner.ps1
  4. ทำตามที่หน้าจอบอก (พิมพ์ Y, ใส่ชื่อ Roblox)
  5. เมื่อเสร็จจะได้ รหัสสแกน 6 ตัว ให้ส่งรหัสนี้ให้แอดมิน

ดาวน์โหลด scanner.ps1

ถ้าขึ้นเตือนว่าไฟล์อาจเป็นอันตราย ให้กดจุดสามจุด (⋯) ในรายการดาวน์โหลดแล้วเลือก "เก็บไว้" ได้ เพราะเป็นไฟล์ข้อความที่คุณเปิดอ่านเองได้

โหลดไม่ได้? ใช้วิธีสำรอง

วิธี A: โหลดเป็น .txt แล้วเปลี่ยนชื่อ (เบราว์เซอร์ไม่บล็อกไฟล์ .txt)

  1. กดดาวน์โหลด scanner.txt
  2. ใน File Explorer เปิด View > Show > File name extensions ให้ติ๊กถูก
  3. คลิกขวาไฟล์ scanner.txt เลือก Rename แล้วเปลี่ยนเป็น scanner.ps1 (กด Yes ถ้าถามยืนยัน)
  4. ไปต่อที่ขั้นตอนที่ 2 ของ "วิธีใช้" ด้านบน

วิธี B: คัดลอกโค้ดไปบันทึกเอง

  2. เปิด Notepad แล้ววาง (Ctrl+V)
  3. เลือก File > Save as ตั้งชื่อ scanner.ps1 เลือก Save as type เป็น All files และ Encoding เป็น UTF-8 with BOM (ถ้าไม่มีตัวเลือกนี้ ให้เลือก UTF-8)
